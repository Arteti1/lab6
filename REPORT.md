## 2. Контрольне запитання

**Запитання:** Як можна форматувати числа у Python (наприклад, виводити з певною кількістю знаків після коми)?

**Відповідь:**
У Python є кілька основних способів форматування чисел:
1. **f-рядки (форматовані рядкові літерали)** — найсучасніший та найрекомендованіший спосіб. Для виведення числа з певною кількістю знаків після коми використовується конструкція `:.Nf`, де `N` — кількість знаків.
   *Приклад:* `pi = 3.14159265; print(f"{pi:.2f}")` виведе `3.14`.
2. **Метод `.format()`** — використовує аналогічний синтаксис всередині фігурних дужок.
   *Приклад:* `print("{:.2f}".format(pi))`
3. **Вбудована функція `round(number, ndigits)`** — округлює число до вказаної кількості знаків, проте варто пам'ятати, що вона повертає число з плаваючою комою, яке може не відображати нулі на кінці (наприклад, `round(3.149, 2)` поверне `3.15`, але при виводі через `print` зайві нулі відкидаються).
